Biblioteka

Puknij utwory, których jeszcze nie ma w albumie, a potem „Dodaj do albumu".

  • Brak wybranego folderu. Kliknij ikonę foldera na dole albo upuść pliki audio na okno.

Brak albumów. Przejdź do „Utwory", kliknij „Zaznacz utwory" i stwórz pierwszy album, albo użyj „+ Nowy album".

Przeglądaj
YouTube bez mostka nie zadziała — publiczne API są dziś blokowane przez YouTube. Mostek to 2 kroki: ① python -m pip install -U yt-dlp ② node ytdl-bridge.mjs (obok muzyka.html, zostaw otwarte). Wyszukiwanie działa normalnie — uruchom mostek, aby słuchać i zapisywać utwory.

YouTube: wklej link w pole wyszukiwania albo szukaj frazą. Podgląd i „Zapisz” (MP3) wymagają lokalnego mostka yt-dlp — status w górnym pasku („● yt-dlp”). Linki do playlist wklej w to samo pole. iTunes i Deezer udostępniają 30-sekundowe podglądy. Audius, Internet Archive i Wikimedia Commons mogą udostępniać pełne pliki.
